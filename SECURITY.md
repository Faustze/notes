# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by opening a [GitHub Issue](https://github.com/faustze/notes/issues) or contacting the maintainer directly at `faustze9@gmail.com`.

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- Any relevant logs or screenshots

We will acknowledge your report and work to address it as soon as possible.
