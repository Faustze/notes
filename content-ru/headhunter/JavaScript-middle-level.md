5) **Что произойдёт при выполнении кода?**  
```typescript
function createCounter() {
  let count = 0;
  return {
    increment() {
      count++;
      return count;
    }
  };
}  
const counter = createCounter();
console.log(counter.increment());
``` 
==-> Метод increment использует замыкание для доступа к count и увеличивает его;==  
(другие варианты: Каждый вызов increment возвращает 1, потому что count пересоздаётся и увеличивается на 1 каждый раз; Создаётся глобальная переменная count вместе с методом increment в counter, который увеличивает count; Функция createCounter ничего не возвращает; count становится недоступным после первой итерации;)
